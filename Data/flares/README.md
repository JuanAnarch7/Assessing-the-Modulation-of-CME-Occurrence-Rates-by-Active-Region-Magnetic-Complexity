# Flares (GOES X-ray flare catalogues)

This folder holds the solar flare catalogues and the scripts that download and process them, to add flare activity to the monthly master dataset and to test hypothesis H4 (flares as the link between active-region properties and CME occurrence).

## Contents

| Path | Type | Description |
|---|---|---|
| `download_flares_hek.py` | script | Downloads the NOAA/SWPC GOES flare list from the HEK (SunPy), one month per query |
| `flares_builder.py` | script (in preparation) | Scale homogenisation, de-duplication, region and CME association, monthly aggregation |
| `raw/flares_swpc_hek_raw.csv` | raw input | SWPC flare list, 1996-01 → 2026-07 (downloaded 2026-10-24) |
| `raw/hek_download_status.csv` | raw input | Status of each monthly HEK query |
| `raw/FlareList_1986-2002.csv`, `raw/FlareList_2003-2020.csv` | raw input (optional) | Catalogue of Plutino et al. (2023) |
| `raw/SHA256SUMS` | checksums | SHA-256 of every file in `raw/` |
| `hek_cache/` | cache, not versioned | One CSV per month from the HEK |

## Quick start

```bash
cd Data/flares
pip install "sunpy[net]"
python download_flares_hek.py --start 1996-01 --end 2026-07          # writes raw/flares_swpc_hek_raw.csv
python download_flares_hek.py --start 1996-01 --end 2026-07 --retry-empty   # re-query empty months
```

The download can be interrupted and resumed: months already in `hek_cache/` with status `ok` are not queried again.

### 1. NOAA/SWPC GOES flare list (HEK)

#### Provenance

- **Origin:** the GOES X-ray flare event list compiled by NOAA's Space Weather Prediction Center (SWPC), as served by the [Heliophysics Events Knowledgebase (HEK)](https://www.lmsal.com/hek/).
- **Retrieved with:** `download_flares_hek.py` (SunPy `Fido` HEK client), one query per calendar month, filter `event_type = FL` and `FRM_NAME = SWPC`.
- **Download date:** 2026-10-24. The HEK can be revised; re-downloading may give slightly different results.
- **Command:**

  ```bash
  python download_flares_hek.py --start 1996-01 --end 2026-07
  ```

#### Files

| File | One row per | Description |
|---|---|---|
| `raw/flares_swpc_hek_raw.csv` | Flare event | All monthly HEK results concatenated, columns as returned by the HEK (below) |
| `raw/hek_download_status.csv` | Calendar month | `status` (`ok` / `empty` / `error`) and `n_events` of each monthly query |

The per-month cache (`hek_cache/`) is not versioned; it can be regenerated by the download script.

#### Columns of `raw/flares_swpc_hek_raw.csv`

| Column | Description |
|---|---|
| `event_starttime`, `event_peaktime`, `event_endtime` | Start, peak and end of the flare (UT, ISO format) in the GOES 1–8 Å channel |
| `fl_goescls` | GOES class as published by SWPC (e.g. `M2.3`); see [scale](#goes-flux-scale) |
| `fl_peakflux`, `fl_peakfluxunit` | Peak flux and its unit, when provided |
| `ar_noaanum` | NOAA region number assigned by SWPC; `0` or empty when no region was assigned. May be printed with 4 or 5 digits |
| `hgs_x`, `hgs_y` | Heliographic Stonyhurst longitude and latitude (degrees), when available |
| `hgc_x`, `hgc_y` | Heliographic Carrington longitude and latitude (degrees), when available |
| `hpc_x`, `hpc_y` | Helioprojective coordinates (arcsec), when available |
| `frm_name`, `frm_identifier`, `frm_institute` | Feature recognition method: `SWPC` for all events |
| `obs_observatory`, `obs_instrument`, `obs_channelid` | `GOES`, `GOES`, `XRA` for all events (the individual GOES satellite is **not** given) |
| `kb_archivid` | HEK unique identifier of the event |

Columns not returned by the HEK for a given month are absent from that month's cache and empty in the concatenated file.

#### Download summary (2026-10-24)

| Quantity | Value |
|---|---|
| Events | 56 270 |
| Period | 1996 → 2026-07 |
| With NOAA region number | 57.1 % of all events; 70.2 % of M and X flares |
| Observatory / instrument / channel | GOES / GOES / XRA for every event |
| Duplicated (peak time, class) pairs | 169 |

#### Known issues

1. **GOES flux scale.** <a name="goes-flux-scale"></a> Classes from GOES-15 and earlier include the historical SWPC scaling factor of 0.7 ("classic" scale). Classes from GOES-16 onward are on the true-flux scale, about 1/0.7 ≈ 1.43 times larger for the same flare. The HEK does not identify the satellite, so the date of the change has to be checked against NOAA documentation and verified in the data (jump in the M/X-to-C ratio and in M/X flares per unit spot area around 2020; comparison with Plutino et al. over 2017–2020). `flares_builder.py` will convert all classes to the classic scale and keep the true-scale flux in a separate column.
2. **Duplicates.** 169 pairs share peak time and class (the same flare listed twice). They will be removed after checking whether they differ in region or position.
3. **Flares without a region.** About 30 % of M/X flares have no NOAA region, mostly near or behind the limb. They are kept, flagged, and their monthly fraction is reported.
4. **Region numbers.** `ar_noaanum` may use 4 digits (modulo 10 000, as in the SRS) or 5 digits; it will be normalised to the full NOAA number (`noaa_full`) before matching with `../active_regions/mount_wilson_dataset.csv`.
5. **C-class completeness.** Weak C flares are missed when the X-ray background is high (solar maximum). The main analysis uses M and X flares; C counts are kept for robustness tests only.
6. **Data gaps.** GOES observing gaps are not flagged by the HEK; months with unusually low counts relative to spot activity will be checked, as was done for LASCO.

### 2. Plutino et al. (2023) catalogue

#### Provenance

- **Reference:** Plutino, N., Berrilli, F., Del Moro, D., & Giovannelli, L. (2023), "A new catalogue of solar flare events from soft X-ray GOES signal in the period 1986–2020", [arXiv:2211.10189](https://arxiv.org/abs/2211.10189).
- **Files:** copied from [github.com/nplutino/FlareList](https://github.com/nplutino/FlareList) (cloned 2026-10-24).
- **Extension:** a version extended to 2023-04-30 exists at [doi:10.5281/zenodo.10560188](https://doi.org/10.5281/zenodo.10560188) (not included yet).

#### Columns

| Column | Description |
|---|---|
| `singleID` | Event counter |
| `multipleID` | Events sharing this value overlap in time and can be treated as one event |
| `tstart`, `tpeak`, `tend` | Start, peak and end time (UT) |
| `fclass` | Class from the peak flux |
| `BG_flux` | Background flux at the start of the event (W m⁻²) |
| `peak_flux` | Peak flux, not background-subtracted (W m⁻²) |
| `flux_integral` | Time integral of the flux from start to end (W m⁻² s) |

#### Notes

- Peak fluxes are already divided by 0.7 (GOES-16 / true-flux scale); the classic NOAA class is recovered with `peak_flux × 0.7`. With that conversion the catalogue gives 122 X flares in 1996–2008 and about 44 in 2009–2019, close to the official counts.
- No NOAA region number or flare position.
- Background-subtracted classes (`peak_flux − BG_flux`) are not biased by the solar-cycle background and are useful for C-class robustness tests.
- Used in the preliminary flare analysis (1996–2020).
